# Healthcare Analytics for Patient Outcomes & Hospital Performance

## Project Overview

This graduation project aims to turn synthetic healthcare data into useful insights through data analysis and interactive dashboards.

Using Python, SQL, and Power BI, we prepare, explore, and analyze healthcare data to understand patient outcomes, evaluate hospital performance, identify operational issues, and visualize key trends that can support better resource planning and decision-making.

## Project Objectives

- Analyze patient encounters, ICU admissions, treatments, laboratory tests, appointments, and mortality records.
- Explore patient outcomes and hospital performance through meaningful metrics and trends.
- Identify operational bottlenecks and opportunities to improve resource utilization.
- Build interactive Power BI dashboards to communicate findings clearly.
- Apply structured database design and SQL analysis to support reliable reporting.

## Project Workflow

1. **Data Understanding & Profiling** – Explore the source tables, understand their grain and relationships, and document data-quality issues.
2. **Data Cleaning & Preparation** – Use Python and Pandas in Jupyter Notebook to profile, clean, and prepare the data.
3. **Database Design & SQL Analysis** – Design the relational database, apply 3NF normalization, build the analytical Galaxy Schema, and perform SQL analysis.
4. **Business Intelligence & Visualization** – Develop Power BI reports and interactive dashboards using DAX measures and visualizations.
5. **Documentation & Presentation** – Document the project and present its methodology, analysis, and findings.

## Technologies & Tools

- **Data Preparation & Analysis:** Python, Pandas, Jupyter Notebook
- **Database Management & Querying:** Microsoft SQL Server, T-SQL, SQL Server Management Studio (SSMS)
- **Database Design & Modeling:** ERD, Relational Modeling, 3NF Normalization, Dimensional Modeling, Galaxy Schema (Fact Constellation)
- **Business Intelligence & Visualization:** Microsoft Power BI, DAX
- **Spreadsheets & Data Formats:** Microsoft Excel, CSV
- **Version Control & Collaboration:** Git, GitHub
- **Presentation:** Microsoft PowerPoint
